# 🕸️ Website Project — Marvel Rivals Fan Site

A multi-page fan site built during the [CODE Lancashire](https://codelancashire.co.uk) coding bootcamp, created to practise HTML, CSS and JavaScript fundamentals using Marvel Rivals as the subject matter.

## 💡 What it does

A static multi-page site including an artwork page and a characters page, built to practise structuring and styling a multi-page site and adding interactivity with JavaScript.

## 🛠️ Tech stack

- HTML
- CSS
- JavaScript

## ⚠️ Note

This is a fan project built purely for learning purposes, using Marvel Rivals artwork and character references as practice material. Not intended as an original or commercial project.

## 📌 Status

Bootcamp learning exercise, completed early in the course before moving on to framework-based work (React) later.
